# Gunz Developer Portfolio

Portfolio one-page yang dibuat dengan HTML, CSS, dan JavaScript vanilla.

## Struktur
- `index.html` — struktur halaman + konten
- `style.css` — visual, responsive layout, animasi
- `script.js` — mobile menu, reveal animation, cursor glow, copy email

## Cara menjalankan
Cukup buka `index.html` di browser.

## Sebelum dipublish
1. Ganti `your@email.com` di `index.html` dengan email asli.
2. Tambahkan link GitHub/LinkedIn/Roblox bila sudah siap.
3. Jika punya screenshot project asli, ganti visual mockup di bagian project dengan screenshot tersebut.
4. Publish ke GitHub Pages, Netlify, Vercel, atau hosting biasa.
